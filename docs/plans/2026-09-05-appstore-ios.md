## Решения, которые уже приняты

- **Подаём в App Store.** Риск по гайдлайну 2.5.4 признан приемлемым.

  без единой ссылки на `AVPictureInPictureController`; `YES` возвращает слой
  целиком. Фон держит только тихое аудио в `BackgroundKeepAliveService`.
- **iPad оставляем.** `TARGETED_DEVICE_FAMILY` остаётся `1,2`, скриншоты 13"
  обязательны.
- **Имя в англоязычной витрине — «Corvin Voice».** «Corvin» там занято чужим
  аккаунтом.
- **macOS в App Store не идёт** — только DMG в релизах GitHub.

## Осталось: что нужно от вас

Три вещи, которых **нет в App Store Connect API** — только веб-интерфейс.

- [ ] **Статус трейдера (DSA).** *App Store Connect → Business → Trader Status*,
      от Hyperstack LLC: юридическое название, адрес, телефон, email. Apple
      проверяет документами, это занимает время — начните заранее, без этого
      приложение не уйдёт в ЕС.
- [ ] **App Privacy.** *App Store Connect → приложение → App Privacy → Get
      Started*. Для Corvin честный ответ — **«Data Not Collected»**: аналитики
      нет, учётных записей нет, наружу не уходит ничего. Ответьте «No» на
      первый вопрос о сборе данных, и раздел закроется.
- [ ] **Цена и территории.** *Pricing and Availability*. Приложение бесплатное
      (in-app purchase не заведены). Список стран — ваше решение; сейчас
      территории не выбраны вообще, без них подача не пройдёт.
- [ ] **Прочитать описание и review notes** перед отправкой. Notes честно
      объясняют, зачем нужен фоновый аудио-режим, включая то, что приложение
      держит аудиосессию почти беззвучным тоном. Это осознанный выбор: если
      ревьюер найдёт это сам, будет хуже.

## Каталог моделей — отдельный контур

**Не связан ни с релизом приложения, ни с подачей в App Store.** Для публикации
в App Store доступ к серверу не нужен вообще.

Доступ к `reactor` понадобится в двух случаях:

1. **Сейчас, один раз** — выложить страницы политики и поддержки на
   `hyperstack.ru` (пункт выше). Это статика рядом с `models.json`.
2. **Каждый раз, когда меняется список моделей.** Никакой привязки к релизам:
   манифест можно обновить хоть в день подачи, хоть через полгода, клиенты
   подхватят его при следующем запуске.

### Как обновить модель в манифесте

```bash
# 1. Отредактировать WhisperModel.all в Shared/Core/ModelManager.swift
#    — это источник правды о том, какие модели существуют,
#      и одновременно офлайн-фолбэк на случай недоступности манифеста.
# 2. Опубликовать:
./scripts/publish-models-manifest.sh --dry-run   # собрать и проверить локально
./scripts/publish-models-manifest.sh             # собрать, залить, сверить
```

Скрипт сам:

- парсит Swift-массив;
- вытягивает **sha256 и точный размер в байтах из LFS-метаданных Hugging Face** —
  руками эти поля не поддерживаются никогда;
- отказывается публиковать манифест, если хоть по одной модели метаданные не
  сошлись;
- заливает через временный файл и `mv`, чтобы читатель никогда не увидел
  половину файла;
- проверяет, что отданная сервером копия совпадает с локальной по sha256.

### Что при этом происходит у пользователя

- Модель считается устаревшей, если sha256 в манифесте отличается от записи в
  `Models/installed-models.json`. Тогда в списке появляется кнопка **Обновить**.
- **Ничего не скачивается само** — файлы весят до гигабайтов, решение за
  пользователем. Устаревшая модель продолжает работать.
- Новые id поднимают бейдж на вкладке «Модели» (iOS) или баннер (macOS),
  гаснет при открытии списка. На чистой установке первый каталог принимается
  молча.
- Скачанный файл проверяется по sha256 до того, как попадёт в каталог моделей;
  при несовпадении удаляется.
- Поле `minAppVersion` (сейчас `1.3.0` у всех) позволяет добавить модель,
  которую увидят только сборки новее указанной.

`small-q5_1` (190 МБ), `base-q5_1` (60 МБ), `tiny-q5_1` (32 МБ),
`medium-q8_0` (823 МБ). Решение не принято — это ровно одна публикация
манифеста, приложение обновлять не нужно.
